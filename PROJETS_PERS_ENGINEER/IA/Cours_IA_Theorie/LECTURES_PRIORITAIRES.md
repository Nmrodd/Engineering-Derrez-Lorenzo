# Bibliothèque prioritaire — ordre de lecture concret

**Tu n'as pas besoin de tout lire.** La règle est : ce cours français + **une référence principale** par bloc. Ne commence les ouvrages avancés que lorsque le projet les rend nécessaires.

## Fondations (Mois 1)

1. **Mathématiques** — Deisenroth, Faisal, Ong, *Mathematics for Machine Learning*, <https://mml-book.github.io/>. Sections pertinentes : algèbre linéaire, dérivées, probas, optimisation.
2. **Apprentissage statistique** — James et al., *An Introduction to Statistical Learning with Applications in Python*, <https://www.statlearning.com/>. C'est le livre prioritaire pour le ML classique et le projet de fraude.
3. **Deep learning** — Zhang et al., *Dive into Deep Learning*, <https://d2l.ai/>. Cours interactif qui combine explications, maths et code.
4. **Exécution PyTorch** — <https://docs.pytorch.org/tutorials/beginner/basics/intro.html>. Suivre l'ordre officiel des six étapes fondamentales.

## Projet Fraude (Mois 2)

- **Principal** : ISLP (régression, classification, arbres, validation). <https://www.statlearning.com/>.
- **Indispensable pour éviter les erreurs** : scikit-learn *Common Pitfalls*. <https://scikit-learn.org/stable/common_pitfalls.html>.
- **Pour évaluer** : scikit-learn *Model Evaluation*. <https://scikit-learn.org/stable/modules/model_evaluation.html>.

## Projet NLP (Mois 3)

- **Principal** : Jurafsky et Martin, *Speech and Language Processing* (manuscrit 2026, encore provisoire). <https://web.stanford.edu/~jurafsky/slp3/>.
- **Implémentation basique** : scikit-learn *Working with Text Data*. <https://scikit-learn.org/stable/tutorial/text_analytics/working_with_text_data.html>.
- **Approfondissement Transformers/LLM** : Hugging Face LLM Course. <https://huggingface.co/learn/llm-course/en/chapter1/1>.

## Projet Rubik's Cube (Mois 4)

- **Principal** : UC Berkeley CS188, recherche non informée puis A* et heuristiques. <https://inst.eecs.berkeley.edu/~cs188/fa26/>.
- **Approfondissement ciblé** : Herbert Kociemba, méthode en deux phases. <https://www.kociemba.org/twophase.htm>.
- **RL en option, après le solveur classique** : Sutton & Barto, *Reinforcement Learning: An Introduction*. <http://incompleteideas.net/book/the-book-2nd.html>.

## Étude avancée des LLM (Mois 5 facultatif)

- **Concepts** : Jurafsky & Martin + original Transformer de Vaswani et al., <https://arxiv.org/abs/1706.03762>.
- **Ingénierie avancée, bien plus tard** : Stanford CS336 (2026), <https://cs336.stanford.edu/>.

## Livres à ne pas acheter immédiatement

- Simon Prince, *Understanding Deep Learning* : très bon approfondissement, livre accessible via <https://udlbook.com/> ; voir les chapitres correspondant aux difficultés rencontrées.
- Russell & Norvig, *Artificial Intelligence: A Modern Approach* : ouvrage universitaire de référence, mais le cours Berkeley CS188 suffit d'abord pour construire le Rubik's Cube.
- Camille Fournier, *The Manager's Path* : développement du leadership ; à lire en parallèle lorsque tu pilotes effectivement un projet avec d'autres personnes.
